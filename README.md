# NoteFerry Companion

This plugin is half of [NoteFerry](https://noteferry.dev). It stays inside Obsidian Desktop.

The other half is the **NoteFerry browser extension**. That is where you choose notes beside ChatGPT, Claude, or Gemini. Enabling this plugin alone does not add a chat, a sidebar, or a button in Obsidian.

## Next step: get the browser extension

1. Open **[noteferry.dev](https://noteferry.dev)** and install NoteFerry.
2. Click the NoteFerry icon in your browser toolbar and choose **Connect Obsidian**.
3. When Obsidian asks, choose **Allow**.
4. In ChatGPT, Claude, or Gemini, open **+** and choose **Add from Obsidian**.

Install page: [noteferry.dev/install](https://noteferry.dev/install)

## What it does

- Lists the note you are editing, recent notes, and search results for the extension.
- Reads only the notes and attachments you choose to add.
- Keeps that access read-only. It does not edit or delete notes.

The connection stays on this computer, between Obsidian and the NoteFerry extension. Notes are not uploaded to NoteFerry. There is no account and no telemetry. A note leaves this computer only when you add it to the AI chat you are using.

You can disconnect the browser from **Settings → NoteFerry Companion**.

3. 在 Obsidian 的提示中选择允许。
4. 在 ChatGPT、Claude 或 Gemini 打开 **+**，选择从 Obsidian 添加。

安装页：[noteferry.dev/zh/install](https://noteferry.dev/zh/install)

插件只读取你选中的笔记，不修改、不删除。连接只发生在这台电脑上的 Obsidian 与 NoteFerry 扩展之间。笔记不会上传到 NoteFerry。没有账号，也没有遥测。只有当你把笔记加入正在使用的 AI 对话时，内容才会离开这台电脑。可在 **设置 → NoteFerry Companion** 里断开浏览器。
